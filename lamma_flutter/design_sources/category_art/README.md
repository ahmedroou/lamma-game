# Category illustrations

Generated with the built-in `image_gen` tool on 2026-10-13. One dedicated generation per category, no external downloads. These are decorative category thumbnails, not authoritative question media (maps/flags must use validated question-specific assets).

Original PNGs and prompts are preserved here in `design_sources/category_art/`, outside Flutter's bundled asset directories. The app uses only 512 x 512 WebP copies in `assets/category_art/`, encoded with sharp 0.35.5, quality 85, effort 6. UI decoding is capped at 300px. All images remain local for offline play. The size of the 14 files decreased from 26,382,660 bytes to 380,100 bytes (98.56%); this measures image assets, not the entire APK/download.

To regenerate, run `node scripts/optimize-category-art.cjs` with sharp available; `SHARP_MODULE` can point to an installed sharp module. See `optimization-report.json` for per-image sizes. No image-generation or design alterations are performed by that script.
