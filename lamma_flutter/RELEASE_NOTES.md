لَمّة 0.2.2 (4) — إصلاح التحديث وإشعار الرئيسية

- إصلاح رفض روابط GitHub الصحيحة التي تحتوي على %2B، وهو سبب رسالة تعذر فحص التحديث رغم وجود الإنترنت.
- زر تحديث صغير أعلى الصفحة الرئيسية مع نقطة إشعار عند توفر إصدار أحدث.
- فحص تلقائي عند الدخول، ثم كل 15 دقيقة أثناء ظهور الرئيسية وفي المقدمة، مع بقاء اللعب محليًا.
- ملف بيانات تحديث خفيف لتقليل الاعتماد على حدود GitHub API، ورسائل خطأ توضح السبب.
- الاحتفاظ بالتحقق من بصمة APK وحجمه وهوية التطبيق وتوقيعه، وبالمباراة المحفوظة.

للنسخ القديمة التي تفشل في فحص التحديث، حمّل هذا APK مباشرة وثبّته فوق التطبيق الموجود مرة واحدة؛ لا تحذف التطبيق حتى تحتفظ ببياناتك. Android يطلب موافقتك للتثبيت. بعد هذا الإصلاح تستخدم زر التحديث داخل التطبيق للإصدارات القادمة.
