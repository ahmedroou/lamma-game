# لَمّة — تطبيق Flutter للجمعات

تطبيق عربي للجوال، يدعم RTL والوضع العمودي والأفقي. الاسم والهوية قابلان للتطوير. مرجع قرارات المنتج الدائم هو [PROJECT_PLAN.md](PROJECT_PLAN.md)، وتعليمات الأدوات في [AGENTS.md](AGENTS.md).

**النسخة الأولى محلية فقط على جهاز واحد.** اللعب عن بُعد والغرف والصوت الجماعي خارج النطاق. الأسئلة الحالية موجودة داخل التطبيق، والبنك الكامل المخطط له سيُضمّن محلياً؛ لا يوجد API أو تسجيل دخول مطلوب للعب. تقرير النواقص: [PROJECT_STATUS_REPORT.ar.md](PROJECT_STATUS_REPORT.ar.md).

## المتاح حالياً

- رئيسية داكنة برسوم كروت أصلية وحركة خفيفة، وشاشتا الفئات وطريقة اللعب.
- اختيار فريقين أو ثلاثة وستة أقسام من مكتبة بداية تضم ثمانية أقسام.
- لوحة أقسام المباراة: ستة مختارة وقسم قدرات سابع تلقائي.
- تجربة محلية بأسئلة عينات، كشف متتابع، مؤقت 30 ثانية، وتحكيم يدوي ونتائج وإعادة اللعب.
- أربعة مستويات للسؤال: 100/200/300/400. الصعوبة محفوظة في النموذج وJSON، والنقاط مشتقة منها.
- مخزون قدرات منفصل لكل فريق، وعقود لتعريف القدرة وتوقيتها وهدفها وتأثيرها وعدد استعمالاتها.
- محرك مخاطرة قابل للتهيئة والاختبار، يدعم مكافأة السؤال + ورقة، أو خصومات 50/100/150.

**قسم القدرات ظاهر ولم يُفعّل للعب بعد**: الأنواع والتأثيرات والاحتمالات وتوقيت الحسم لم يحددها صاحب المشروع بعد. لا توجد أوراق افتراضية أو احتمالات مخفية. مخزون المباراة والإعدادات والنقاط والأسئلة وسجل التحكيم أصبحت تُحفظ محلياً، ويمكن استئناف المباراة بعد إغلاق التطبيق.

## إدارة الجلسة والحفظ

- إيقاف واستئناف صريح، مع إخفاء السؤال أثناء التوقف. الاستعادة والعودة من الخلفية لا تشغلان المؤقت تلقائياً.
- حفظ تلقائي للجلسة الحالية والإعدادات، ونسخة سجل سابقة وفحص سلامة للبيانات. تظهر أخطاء الكتابة وتتاح إعادة المحاولة.
- الرجوع يتيح البقاء أو الحفظ والخروج. بدء جلسة تستبدل الجلسة السابقة أو إعادة المباراة يتطلب تأكيداً.
- سجل الجولات لتصحيح القرار العادي بنقل النقاط، وإعادة فتح آخر تحكيم قبل السؤال التالي، مع حفظ التعديلات.
- حفظ النتيجة الأخيرة وإنهاء مبكر واضح. لا يوجد أرشيف كامل للمباريات أو انتقال أوراق بين مباريات مختلفة.
- قاعدة محلية عبر Sembast في مجلد دعم التطبيق، وIndexedDB للمعاينة على أصل المتصفح نفسه. الإنتاج يبدأ من `LammaBootstrap`؛ مستودع الذاكرة مخصص للاختبارات والمعاينات المعزولة.

التصحيح لا يعيد الحظ ولا يصنع ورقة جديدة. جولة قدرات أو قرار تلاه استخدام قدرة لا يعدلان بهذه الطريقة قبل تعريف قواعدهما. النسخة السابقة حماية لسجل داخل القاعدة، وليست نسخة مستقلة خارج الجهاز. الإغلاق القسري يعيد آخر حفظ ناجح؛ حذف بيانات التطبيق يحذف حفظه المحلي.

قواعد التجربة الحالية (وليست قرارات نهائية لكل اللعبة): الدور يتناوب بين الفرق، سؤال عينة واحد لكل قسم، تنتهي التجربة بنفاد الأسئلة، 30 ثانية، دون خصم على الإجابة العادية الخاطئة، وإيقاف العداد أثناء وجود التطبيق في الخلفية. تُحسم القواعد النهائية مع توسيع اللعبة.

## التشغيل

نفذ من هذا المجلد على جهاز فيه Flutter وأدوات المنصة:

```powershell
flutter pub get
flutter run
```

عند عدم إضافة SDK الحالي إلى PATH:

```powershell
& 'C:\Users\Admin\.cache\flutter-celebrations-sdk\bin\flutter.bat' run -d chrome
```

معاينة المتصفح تستخدم **نفس كود Flutter**:

```powershell
flutter build web --no-web-resources-cdn
node scripts/preview.mjs
```

الرابط المحلي: http://127.0.0.1:5274/ . لا يوجد Android SDK على الجهاز وقت التنفيذ، لذلك لم يُنتج APK. ملفات Android وiOS موجودة؛ بناء iOS والتحقق منه يحتاج macOS وXcode.

## البنية والتوسعة

- `domain/models/`: أسئلة وصعوبة وفرق وأوراق وإعداد جلسة، مع التحويل إلى JSON.
- `domain/abilities/`: سجل تعريفات وتأثيرات، خدمة استعمال أوراق، وسياسة ومحرك مخاطرة.
- `data/repositories/question_repository.dart`: مصدر أسئلة محلي يُحقن في حالة المباراة؛ استبدله ببنك ملفات محلي منظم لاحقاً.
- `features/session/session_view_model.dart`: الحالة والتوقيت والتحكيم وتوزيع الأدوار. يمتلك عقْد `RiskRoundResolver` لربط قرار الحظ بالإجابة دون افتراض قاعدة لم تُحسم.
- `features/`: واجهات العرض والتفاعلات والتنقل، مفصولة عن حساب النقاط.
- `docs/question-example.json`: مثال صيغة سؤال، مع صعوبة إلزامية.
- `screenshots/`: صور من العرض الفعلي عبر اختبارات Flutter للمراجعة.

عند إضافة نوع قدرة: عرّف `AbilityDefinition` وسجل `AbilityEffect` بالمفتاح نفسه. تأثير القدرة يتحقق أولاً، ثم تُطبق النتيجة وتُستهلك الورقة في عملية واحدة. اجعل `RiskPolicy` صريحة الاحتمالات وسياسة الخصم، ثم صلها بعقد `RiskRoundResolver` بعد تثبيت توقيت المخاطرة. اختبارات الأنواع الوهمية تستخدم تجهيزات اختبار فقط، وليست قدرات مقترحة للمنتج.

## التحقق

استخدم أدوات Dart MCP وفق تعليمات المشروع، أو أوامر SDK عند عدم توفرها:

```powershell
flutter analyze
flutter test
```

التغطية تشمل 2–3 فرق، ستة أقسام، تحويل السؤال والمخزون إلى JSON، نطاق أسئلة القدرات، الخصومات الثلاثة، ملكية الورقة وتوقيتها وهدفها واستهلاكها، التوقيت، منع ازدواج مكافأة الجولة، والتنقل والمقاسات والنص المكبر.

خط Tajawal مضمّن محلياً؛ ترخيصه في `assets/fonts/OFL.txt`. لا يعتمد التطبيق على الموقع المرجعي أو ينزّل أسئلته أو أصوله.
