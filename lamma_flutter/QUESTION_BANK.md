# بنك الأسئلة المحلي

المصدر الفعلي للتطبيق هو `assets/questions/`: ملف JSON مستقل لكل قسم. لا توجد أسئلة إنتاجية ثابتة في Dart. تُحمّل الملفات محليًا قبل بدء الجلسة وتُفحص بنيتها، وتُحفظ نسخة أسئلة المباراة ضمن الحفظ المحلي حتى لا يغيّر تعديل البنك مباراة جارية.

الحالة الحالية بعد دمج توسعة 13 أكتوبر 2026: **12600 سؤال، 900 لكل قسم و225 لكل صعوبة**. أضيف 1400 سؤال وأُعيد تأليف 1999 سجل تالف معروف في معرفاته، مع إصلاحات إضافية للتكرار والنسب التاريخية. لا يوجد حشو معروف أو عزل متبقٍ في الدفعة. الملفات `draft`: العدد وفحوص البنية ليسا شهادة دقة تحريرية لكل سؤال. راجع `QUESTION_EXPANSION_REVIEW.md` و`QUESTION_EXPANSION_VALIDATION.json` للأعداد والبصمات وحدود المراجعة. بيانات `test/fixtures/` لا تُضمّن في التطبيق.

## التوسعة الجديدة

طلب المستخدم إعادة تأليف التالف وإضافة 100 سؤال لكل قسم. الهدف الحالي 12600 سؤال: 900 لكل قسم و225 لكل صعوبة. تحفظ المعرفات السابقة وتضاف 0201–0225 لكل مستوى. لا تعتبر أعداد الدفعة السابقة أعلاه وصفاً نهائياً لنتائج التوسعة.

## الأقسام
- `myths`: الأساطير والخرافات
- `spacetoon`: سبيستون
- `breaking_news`: الأخبار العاجلة
- `complete_verse`: أكمل الآية
- `complete_hadith`: أكمل الحديث
- `how_it_works`: كيف تعمل؟
- `geography`: جغرافيا
- `maps`: خرائط
- `flags`: أعلام
- `riddles`: ألغاز
- `meanings`: معاني
- `islamic_history`: تاريخ إسلامي
- `notable_figures`: علماء وأعلام
- `who_am_i`: من أنا؟

## الملف
```json
{
  "schemaVersion": 1,
  "categoryId": "maps",
  "targetCount": 900,
  "targetPerDifficulty": 225,
  "status": "draft",
  "questions": [
    {
      "id": "maps-medium-0001",
      "categoryId": "maps",
      "difficulty": "medium",
      "text": "على خريطة بمقياس 1 : 100000، كم كيلومترًا تمثّل 3 سم؟",
      "answer": "3 كيلومترات",
      "options": [
        {"id": "A", "text": "كيلومتران"},
        {"id": "B", "text": "2.5 كيلومتر"},
        {"id": "C", "text": "3 كيلومترات"},
        {"id": "D", "text": "3.5 كيلومتر"},
        {"id": "E", "text": "4 كيلومترات"},
        {"id": "F", "text": "4.5 كيلومتر"}
      ],
      "correctOptionId": "C",
      "acceptedAnswers": ["3 كم", "ثلاثة كيلومترات"],
      "hint": "حوّل السنتيمترات على الأرض إلى أمتار ثم إلى كيلومترات.",
      "clues": [],
      "explanation": "3 × 100000 = 300000 سم، أي 3 كيلومترات.",
      "sources": ["مسألة حسابية أصلية؛ التحقق: تحويل وحدات الطول."]
    }
  ]
}
```

- الصعوبات: `easy` 100، `medium` 200، `hard` 300، `legendary` 400 نقطة. لا تضف حقل points.
- `hint`: مساعد متوسط إلزامي؛ عرضه في السؤال العادي مشروط بإذن قدرة أو ورقة بداية معتمدة كما في PROJECT_PLAN، وليس مساعدة مجانية. لا يوجد خصم إضافي معتمد له.
- `options`: **ستة خيارات بالضبط لكل سؤال**، بمعرّفات A إلى F ونصوص مختلفة ومتقاربة في الموضوع والنوع والطول ومستوى التفاصيل. `correctOptionId` يطابق معرّف خيار واحد، ونصه يساوي الإجابة المرجعية أو أحد بدائلها المقبولة. لا توجد إجابة مقبولة ثانية بين المشتتات.
- الخيارات مخزنة فقط، وتُحفظ مع الجلسة ولا تُعرض في شاشة السؤال أو شاشة الإجابة. ربط عرضها بقدرة أو ورقة بداية مؤجل لتعريف المستخدم؛ لا تأثير ولا شرط استعمال مفترض الآن.
- `clues`: فارغة للسؤال العادي؛ ثلاث عبارات غير فارغة ومختلفة لقسم `who_am_i`.
- `explanation`: شرح الإجابة يظهر بعد كشفها. `acceptedAnswers`: بدائل معروضة للمحكّم، وليس تصحيحًا آليًا.
- `sources`: روابط وصفحات/مراجع تمت قراءتها وتدعم السؤال. يسرد المصدر الديني السورة والآية أو الكتاب ورقم الحديث؛ يُسمح بإثبات أصلي للألغاز المؤلفة والمسائل الحسابية.
- `imageAsset` و`imageDescription` اختياريان معًا. المسار المحلي يبدأ بـ`assets/question_media/` ويفضل ملفًا مباشرًا في هذا المجلد، بصيغة PNG/JPG/WebP. أي مجلد فرعي يحتاج إدراجه في pubspec.yaml. الوصف يشرح الصورة دون تسريب الجواب.
- المعرّفات ثابتة وفريدة: `categoryId-difficulty-0001` حتى `0225` لكل صعوبة.
- الحالات: sample للعينات، draft أثناء التعبئة، complete بعد إكمال العدد والمراجعة.
- `qualityStatus` اختياري للتوافق مع القديم: `unreviewed` افتراضيًا، `reviewed` فقط بعد تدقيق السؤال والجواب والمصدر والتلميح والخيارات الستة، أو `quarantined` مع قائمة `qualityReasons` غير فارغة. لا تمنح الاختبارات الآلية وسم reviewed.
- المستودع يستبعد quarantined والحشو المعروف من تحميل بنك المباريات الجديدة، ويحسب التوفر من الناتج. يبقى التحقق البنيوي على كل السجلات حتى المعزولة؛ أصلح العيب البنيوي ولا تستخدم الحجر لتجاوز فحص JSON أو الخيارات.
- الجلسات المحفوظة تحتفظ بنسختها السابقة ونقاطها وتاريخها؛ يظهر تنبيه إذا احتوت حشوًا معروفًا. لا تُغيَّر أسئلة حكمت سابقًا تلقائيًا. بدء مباراة جديدة يستخدم البنك المصفّى، ولا يمسح سجل مشاهدة الجهاز.

## من أنا؟
يبدأ اللاعب بزر كشف التلميح الأول ويبدأ معه مؤقت الجولة. لا كشف تلقائي للتلميح التالي؛ زر الكشف يوضح النقاط التي ستبقى. تظهر التلميحات السابقة مع الجديدة، ولا يمكن العودة لعدد أقل.

| الصعوبة | الأول | الثاني | الثالث |
|---|---:|---:|---:|
| easy | 100 | 50 | 25 |
| medium | 200 | 100 | 50 |
| hard | 300 | 150 | 75 |
| legendary | 400 | 200 | 100 |

يُحفظ عدد التلميحات مع حالة الجولة وسجل التحكيم، وتستخدمه استعادة الجلسة وتصحيح الحكم وإعادة فتحه. لا يعاد ضبط الوقت بكشف تلميح. حقل hint يبقى ضمن سجل «من أنا؟» للمساعدة التحريرية؛ لا يظهر كتلميح رابع أثناء اللعب. بقية قواعد المؤقت التجريبية ثابتة حتى قرار جديد.

## التحقق
- فحص التطوير: `test/data/question_bank_test.dart`. يقبل البنك الجزئي ويمنع تجاوز 225 سؤالاً للصعوبة.
- بوابة اكتمال البنك: `tool/question_bank_release_test.dart`؛ تتطلب 900/225 وstatus=complete ومصادر وqualityStatus=reviewed لكل سؤال وعدم الحجر. فشلها متوقع حاليًا، وهو نقص جودة يجب إظهاره.
- فرز تحريري آلي: `python tool/audit_question_quality.py --strict` ينتج التقرير JSON/Markdown ويرفض الإصدار مع عيوب مؤكدة. `--quarantine` يوسم الحشو المعروف فقط؛ لا يحذف أو يعيد ترقيم السجلات ولا يفك حجر سؤال تلقائيًا.
- جميع الاختبارات: مجلد `test/`. تشغيل بوابة الاكتمال خارج هذا المجلد مقصود كي لا تعطل تطوير التطبيق قبل تعبئة المحتوى.
- التحقق البنيوي لا يغني عن مراجعة الحقائق والتلميحات والتكرار المعنوي.
- برومبت التأليف الكامل: `QUESTION_AUTHORING_PROMPT.md`.
