# لَمّة — لعبة البطاقات والأسئلة

مشروع لعبة جماعية عربية تعمل محليًا على جهاز مشترك، مع حفظ الجلسات وسجل استخدام الأسئلة على الجهاز.

## مجلدات المشروع

- `lamma_flutter/`: التطبيق الأساسي المبني باستخدام Flutter.
- `lamma/`: نموذج ويب منفصل.
- `research/`: مواد البحث والتصميم.

ابدأ بقراءة `AGENTS.md` ثم تعليمات التطبيق و`PROJECT_PLAN.md` داخل `lamma_flutter/`.

## تشغيل التطبيق

من مجلد `lamma_flutter/`:

```sh
flutter pub get
flutter run -d chrome
```

للفحص والبناء:

```sh
flutter analyze
flutter test
flutter build web
python tool/verify_bank_expansion.py
python tool/audit_question_quality.py --strict
```

## بنك الأسئلة

توجد ملفات الأقسام الأربعة عشر في `lamma_flutter/assets/questions/`، والصور محلية في `assets/question_media/`. الهدف الحالي 900 سؤال لكل قسم، بواقع 225 لكل صعوبة، بإجمالي 12600 سؤال. كل سؤال يتضمن تلميحًا وستة خيارات محفوظة للاستخدام عبر القدرات لاحقًا.

اقرأ `QUESTION_BANK.md` و`QUESTION_AUTHORING_PROMPT.md` قبل التأليف. فحوص البنية لا تغني عن مراجعة المعنى والمصادر، وتبقى الملفات `draft` حتى إتمام المراجعة التحريرية. توجد نسخ ما قبل التوسعة ودفعات التأليف وتقارير التحقق داخل مجلد التطبيق للحفظ والمقارنة.

ملفات البناء والاعتمادات وبيانات الدخول المحلية مستبعدة من Git. المستودع يحفظ الشفرة والمحتوى والتقارير؛ حفظ جلسات اللعب على جهاز المستخدم منفصل عنه.
