# لَمّة — لعبة البطاقات والأسئلة

مشروع لعبة جماعية عربية تعمل محليًا على جهاز مشترك، مع حفظ الجلسات وسجل استخدام الأسئلة على الجهاز.

تجري حاليًا مراجعة تحريرية فردية للأقسام العشرة الجديدة بواسطة أجنت، بطلب المستخدم ومن دون فحوص جودة آلية. قد تنخفض أعداد الأسئلة مع حذف التكرار والتلف؛ أرقام توسعة3000 أدناه تصف دفعة التأليف قبل المراجعة. القرارات والأدلة والتغطية الفعلية في lamma_flutter/tool/editorial_review، وعقد العمل في EDITORIAL_REVIEW_POLICY.md داخل التطبيق.

## مجلدات المشروع

- `lamma_flutter/`: التطبيق الأساسي المبني باستخدام Flutter.
- `lamma/`: نموذج ويب منفصل.
- `research/`: مواد البحث والتصميم.

ابدأ بقراءة `AGENTS.md` ثم تعليمات التطبيق و`PROJECT_PLAN.md` داخل `lamma_flutter/`.

## تشغيل التطبيق

من مجلد `lamma_flutter/`:

```sh
flutter pub get
flutter run -d chrome
```

للفحص والبناء:

```sh
flutter analyze
flutter test
flutter build web
python tool/assign_question_usage_ids.py --check
python tool/audit_question_quality.py --strict
```

## بنك الأسئلة

توجد 24 ملفًا في lamma_flutter/assets/questions:14 قسمًا×900 وعشرة جديدة×300، بإجمالي 15600 سؤال خام. كل سؤال يتضمن تلميحًا وستة خيارات مخفية تكشفها أوراق المفاجأة المعتمدة. تُفعّل 33 ورقة بفرص متساوية بين المسموح، وتُحفظ تكاليفها وآثارها والرهانات والاستبعاد مع المباراة. اقرأ OPENING_SURPRISE_CARDS.md وNEW_CATEGORY_AUTHORING.md داخل التطبيق.

اقرأ `QUESTION_BANK.md` و`QUESTION_AUTHORING_PROMPT.md` قبل التأليف. فحوص البنية لا تغني عن مراجعة المعنى والمصادر، وتبقى الملفات `draft` حتى إتمام المراجعة التحريرية. توجد نسخ ما قبل التوسعة ودفعات التأليف وتقارير التحقق داخل مجلد التطبيق للحفظ والمقارنة.

ملفات البناء والاعتمادات وبيانات الدخول المحلية مستبعدة من Git. المستودع يحفظ الشفرة والمحتوى والتقارير؛ حفظ جلسات اللعب على جهاز المستخدم منفصل عنه.
