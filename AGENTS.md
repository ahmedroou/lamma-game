# Development workspace

The Flutter app is in `lamma_flutter/`. Run app analysis, tests, package commands,
and debugging with that directory as the project root. Read its `AGENTS.md`
before Flutter work. The sibling `lamma/` is a separate web prototype.

Use the enabled official `dart-flutter@dart-flutter` skills for matching Dart and
Flutter tasks. Prefer the Dart MCP server for SDK operations, Context7 MCP for
current package documentation, Figma MCP for supplied design links, and GitHub
MCP for repository/issue/PR context. Follow the detailed workflow in the app's
instructions. Do not add duplicate integrations.
